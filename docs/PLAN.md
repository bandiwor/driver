# План разработки

Каждый шаг заканчивается зелёным `npm run check`, `npm run build`,
`npm run e2e`, свежими снапшотами затронутых элементов и коммитом.
Шаги выполняются по команде, по одному.

## ✅ Шаг 0 — Каркас (готово)

- [x] Vite 8 + Oxc + Lightning CSS, TS 7 strict, oxlint, Vitest 5, Playwright
- [x] Ядро: Kernel/плагины/токены, EventBus, FixedStepLoop, ParamStore, Rng, math
- [x] Солвер node–beam: пружины, демпферы, пластика, разрыв, земля, трение, детерминизм
- [x] Двигатель, КПП, сцепление, шина Magic Formula, кривые — чистые модули с тестами
- [x] Процедурная решётка кузова из сечений, эталонная машина «Kuzov K1»
- [x] Рендер three.js: окружение без ассетов, деформируемый скин, колёса, оверлей балок
- [x] Камеры: сзади, от первого лица, сверху, орбита + детерминированные проекции
- [x] Процедурный звук двигателя в AudioWorklet, звук удара
- [x] Ввод с клавиатуры со сглаживанием
- [x] UI-кит, иконки, меню, HUD с тахометром, автопанель тюнинга, пауза
- [x] Snapshot-режим + `npm run snap`, e2e `npm run e2e` (dev и prod)
- [x] Документы: ARCHITECTURE, PLAN, STYLE

## ✅ Шаг 1 — Физика в Web Worker (готово)

- [x] `Simulation` (чистая), `PhysicsHost`: `InlineHost` / `WorkerHost`, shadow-машина
- [x] Протокол сообщений, `SimServer` с собственными часами (Atomics.wait + yield)
- [x] SharedArrayBuffer: неблокирующий тройной буфер снапшотов, SAB управления
- [x] Фолбэк `transfer` (пул transferable-буферов) без cross-origin isolation
- [x] Интерполяция по времени снапшота, команды/тюнинг/удары через протокол
- [x] Автофолбэк на inline, `?physics=inline`
- [x] Тесты: тройной буфер, снапшот, WorkerHost ≡ InlineHost (оба транспорта),
      perf `sync()`, e2e в режимах worker·shared / worker·transfer / inline / prod

## ✅ Шаг 2 — Колёса, подвеска, привод (готово)

- [x] Узлы ступиц и опор, рычаги-шарниры, стойки: преднатяг, сжатие/отбой,
      отбойники, ход вниз; стабилизаторы
- [x] Колесо: вращение, инерция, тормоз, ручник; Pacejka с нагрузочной
      чувствительностью, длиной релаксации, сопротивлением качению, развалом, давлением
- [x] Рулевое: Аккерман, схождение, угол руля (скорость/самовозврат — во вводе)
- [x] Неявный привод: двигатель ↔ сцепление (замкнуто/проскальзывает) ↔ КПП ↔
      дифференциал с долями момента (RWD/FWD/AWD) ↔ колёса; блокировка диффа
- [x] Автомат и механика, автосцепление, задний ход в автомате, аэродинамика
- [x] Все параметры тюнинга работают на лету (+ развал, схождение, давление,
      блокировка, привод, угол руля, Аккерман, сила тормозов, автомат)
- [x] Замеры: 0–100 ≈ 7.1 с, 100–0 ≈ 39 м, скидпад ≈ 0.94 g, прямолинейность,

- [x] Snapshot-режим: сценарии вождения `--drive`

## Шаг 3 — Разрушаемость

- Зоны материалов: сминаемые зоны (капот, багажник, пороги) vs жёсткий каркас салона
- Детализация решётки (больше сечений, промежуточные узлы панелей)
- Отрыв панелей/бамперов группами балок, отрыв колёс при разрушении подвески
- Коллизии узел–треугольник с препятствиями, машина–машина, самопересечение
  (spatial hash broadphase)
- Повреждения агрегатов: радиатор/двигатель/подвеска → поведение
- Ремонт (R), снапшот-тесты «до/после удара» во всех проекциях

## Шаг 4 — Мир

- Heightfield-рельеф, типы поверхностей (асфальт, гравий, трава) с μ и звуком
- Тестовый полигон: трамплины, стена для краш-тестов, «стиральная доска»,
  скидпад, серпантин, статические препятствия, отбойники
- Спавн/телепорт, несколько машин в сцене

## Шаг 5 — Звук высокого качества

- Двигатель: смесь впуск/выхлоп/механика, отдельные голоса для камеры салона и снаружи,
  неравномерность по цилиндрам, отсечка-«хлопки», турбо (свист, BOV)
- Трансмиссия (вой прямозуба), визг шин от энергии скольжения, шум покрытия,
  ветер, стуки подвески, хруст металла по энергии деформации, звон стекла
- Пространственный звук (PannerNode), доплер; офлайн-тесты спектров

## Шаг 6 — Визуал

- Детальнее модель: больше сечений, фары/фонари, бамперы, зеркала, ручки,
  колёсные арки; салон: торпедо, руль, анимированные приборы
- Отражения: PMREM-карта окружения из процедурного неба
- Визуальные повреждения: вмятины уже из физики; разбитое стекло, царапины
  (vertex color по пластике), следы шин (decals), дым/искры (instanced)
- Опция WebGPURenderer с фолбэком на WebGL

## Шаг 7 — Камеры

- Chase: пружина с инерцией, обход препятствий, FOV от скорости, тряска
- Салон: обзор мышью, наклон головы от перегрузок
- Сверху: зум, режим «карта»; свободная камера для фото

## Шаг 8 — Гараж и тюнинг

- Пресеты (сохранение/загрузка, JSON-экспорт), сравнение с заводскими
- Живые графики: кривая момента/мощности, ход подвески, слип шин, температура
- Ассистенты: ABS, TCS, ESC — параметрами
- Перенос точки приложения сил шины в пятно контакта (сейчас — в ступицу)

## Шаг 9 — Новые машины

- Хэтчбек, пикап, грузовик; визуальная «витрина» машины с проекциями из snapshot-режима

## Шаг 10 — Устройства ввода

- Геймпад (аналог педалей/руля), руль через Gamepad API, переназначение клавиш в UI

## Шаг 11 — Производительность

- Профилировочный HUD, perf-бюджеты в CI
- Опционально: солвер в WASM SIMD; LOD мешей; instancing

## Шаг 12 — Релиз

- Сохранение настроек, PWA/офлайн, GitHub Actions: check + build + e2e + снапшоты
  как артефакты, визуальная регрессия (pixel diff против эталонов)
