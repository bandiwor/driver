# Стиль: UI и код

## UI — «приборная панель»

Тёмный графит, один акцентный цвет (сигнальный янтарный), моноширинные
табличные цифры для всех значений. Интерфейс не должен спорить с картинкой
игры: тихие поверхности, яркий только акцент и предупреждения.

### Токены (`src/ui/styles/tokens.css`)

| Группа | Токены | Правило |
|---|---|---|
| Поверхности | `--k-bg-0…3`, `--k-line`, `--k-line-strong` | глубже — темнее; панели `bg-1`, контролы `bg-2`, hover `bg-3` |
| Текст | `--k-fg-0` основной, `--k-fg-1` вторичный, `--k-fg-2` подписи | |
| Акцент | `--k-accent`, `--k-accent-hi`, `--k-accent-ink` | только главное действие, активное значение, заполнение шкал |
| Семантика | `--k-ok`, `--k-warn`, `--k-danger`, `--k-info` | состояние (повреждения, отсечка), не декор |
| Отступы | `--k-s1…s7` = 4, 8, 12, 16, 24, 32, 48 px | всё по сетке 4 px |
| Радиусы | `--k-radius-sm` 6, `--k-radius` 10, `--k-radius-lg` 16 | контрол / кнопка / панель |
| Шрифт | `--k-font` (системный sans), `--k-mono` | значения — mono + `tabular-nums` |
| Движение | `--k-dur` 140 мс, `--k-ease` | уважает `prefers-reduced-motion` |

Никаких «сырых» цветов и отступов в компонентах — только токены.

### Компоненты (`src/ui/kit`)

* **Button** — `primary` (одна на экран), `secondary`, `ghost`, `danger`;
  размеры `sm/md/lg`; иконка слева, хоткей (`Kbd`) справа.
* **Slider** — подпись слева, значение справа (mono), единицы приглушены;
  изменённое от заводского значение подсвечено акцентом + кнопка сброса.
* **Toggle**, **Tabs**, **Panel**, **Stat**, **Kbd**, **Gauge** (тахометр: дуга 240°,
  красная зона, передача по центру).
* Каждый контрол доступен с клавиатуры, фокус — кольцо `--k-focus`.

### Иконки (`src/ui/icons/Icon.tsx`)

Сетка 24×24, обводка 2 px, скруглённые концы и стыки, `currentColor`, без
заливок (исключение — `play`). Только path-данные в объекте `ICONS`; тест
проверяет валидность.

### Композиция экранов

* HUD: приборы справа снизу, чипы состояния слева снизу, отладка слева сверху.
  Без `backdrop-filter` поверх WebGL (дорого) — полупрозрачный `--k-hud-bg`.
* Меню/пауза: сетка панелей, scrim с размытием (игра на паузе — можно).
* Тексты: коротко, по-русски, глагол в кнопках («Поехали», «Сбросить машину»).

## Код

* TypeScript только строгий: никаких `any`, `as unknown as`, `@ts-ignore`.
  Индексный доступ — `T | undefined` (`noUncheckedIndexedAccess`); в горячих
  циклах допускается `!` по гарантированным индексам.
* Именование: файлы `camelCase.ts`, компоненты `PascalCase.tsx`, CSS-классы
  `k-block__elem--mod`, токены `--k-*`.
* Модули — маленькие и чистые; побочные эффекты только в плагинах и `main.ts`.
* Комментарий в шапке модуля: что это и почему так. Внутри — только неочевидное.
* Тест рядом с модулем: `foo.ts` → `foo.test.ts`; UI-тесты — `// @vitest-environment happy-dom`.
* Физические тесты формулируются через законы и инварианты, а не «магические числа».
* Новая видимая сущность (машина, деталь, анимация, экран) → снапшот
  (`npm run snap` / `npm run e2e`) проверяется глазами перед коммитом.
